## Technical Features & Architecture

### 1. Direct Engineering Showcase
- **Clean Responsive Layout**: High-contrast, accessibility-focused interface engineered with modern typography, dark mode synchronization, and responsive layouts.
- **Privacy & Terms**: Dedicated standalone policy pages for data transparency and open-source terms of use.

### 2. Full Technical SEO Engine & Schema.org Integration
- **Dynamic Head Metadata**: Dynamic per-page management for title, meta description, keywords, and canonical URLs (`https://codexia-portfolio.vercel.app/`).
- **JSON-LD Structured Data**: Implements Schema.org `Person`, `WebSite`, and `SoftwareSourceCode` schemas for entity recognition in search engines and rich snippets.
- **Social Cards & Open Graph**: Custom 1200x630 Open Graph preview image (`/og-image.png`) with full `og:*` and Twitter card tags.
- **Google Search Console Verified**: Built-in verification file (`googleb4dab4039d740486.html`), XML sitemap (`/sitemap.xml`), and `robots.txt`.

### 3. SSG Static Pre-Rendering Pipeline
- **Automated Post-Build Pre-Renderer**: `scripts/prerender.js` runs automatically during `npm run build` to generate static HTML pages for all routes (`/`, `/projects/trustos`, `/projects/pulseforge-ai`, `/projects/loksetu-ai`, `/projects/jeeratype`, `/projects/wasm-sandbox`, `/privacy`, `/terms`).
- **Fast Crawlability**: Search crawlers and link scrapers receive pre-populated HTML, metadata, and JSON-LD data without requiring client-side JavaScript execution.

### 4. Selected Project Case Studies
Comprehensive architectural breakdowns for 5 core projects:
1. **TrustOS**: Explainable AI Trust Layer for Autonomous Agents (*Python, FastAPI, LLMs, Vector Search, Cryptographic Proofs*).
2. **PulseForge AI**: Strategic Market Intelligence Platform (*React, FastAPI, Gemini API, MongoDB, Tailwind CSS*).
3. **Loksetu.ai**: Privacy-First Browser Copilot for Govt Portals (*React, TypeScript, Chrome Extensions Manifest V3, FastAPI*).
4. **JeeraType**: Offline Cross-Platform Terminal Typing Speed Tester (*Go, Terminal UI, Cross-Platform*).
5. **WASM Sandbox Package Manager**: Capability-Isolated Rust WebAssembly Runtime (*Rust, Wasmtime, WASI, Capability Security*).

## Local Setup & Installation

### Prerequisites
- **Node.js**: v18.0 or higher
- **npm**: v9.0 or higher

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/Codexia-afk/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production (compiles TS, bundles Vite, and runs SSG prerender)
npm run build

# 5. Preview production build
npm run preview
```
